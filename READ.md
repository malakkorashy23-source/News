Online API Project

 About the Project

This project is a web application that depends on an Online API to fetch and display data dynamically.

The project uses JavaScript to communicate with the API and retrieve the required data.

---

 How to Run the Project

Because the project depends on an Online API, you need to download the project to your device before running it.

Steps

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Open "index.html".
5. Right-click on the file.
6. Select Open with Live Server.

« It is recommended to run the project using Live Server instead of opening the HTML file directly.»

---

 API Requests Limit

The project uses an API Key to access the Online API.

Each API Key has a maximum limit of:

100 Requests

The API Key does not have a fixed lifetime of two days.

It remains usable until the 100 requests are consumed. Depending on how frequently the API is used, the limit may be reached within one day, two days, or a longer period.

Therefore, avoid making unnecessary API requests.

---

 Dynamic Date

The project handles the API date dynamically using JavaScript.

The date is automatically updated based on the current date, so there is no need to manually change the date in the project every day.

This makes the project automatically adapt to the current date when making API requests.

---

 Important Notes

- An active internet connection is required.
- The project depends on an external Online API.
- Each API Key has a limit of 100 requests.
- The 100-request limit depends on actual API usage, not on a fixed number of days.
- Avoid unnecessary API calls to preserve the available requests.
- The API date is handled dynamically using JavaScript.
- Run the project using Live Server.
- If the API Key reaches its 100-request limit, another valid API Key may be required.
